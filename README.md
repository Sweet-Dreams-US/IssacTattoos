# RELIQUARY · A Tattoo Parlour by Isaac Roque

Demo concept site for Isaac Roque, tattoo artist in Fort Wayne, Indiana.

**Live demo:** https://sweet-dreams-us.github.io/IssacTattoos/

## Concept

`Reliquary` — a private tattoo parlour and sacred portraiture studio. The brand
treats each piece as a relic: drawn for the body that will carry it, designed
for decades not seasons, finished one client at a time.

## Stack

- Vanilla HTML / CSS / JavaScript — no build step, no framework
- Custom SVG illustrations and animations (no library)
- Google Fonts: Cinzel, EB Garamond, Cormorant Garamond, UnifrakturCook
- Imagery generated with [Higgsfield](https://higgsfield.ai) (gpt_image_2),
  hand-curated and converted to WebP

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server 8000
# → http://localhost:8000
```

## Deploy

Hosted on GitHub Pages from the `main` branch root. The `.nojekyll` file keeps
underscore-prefixed assets working.
